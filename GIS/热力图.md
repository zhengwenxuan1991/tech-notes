# 热力图

## 1. 什么是热力图

热力图（Heatmap）是一种用颜色强弱表示数据分布密度或权重大小的可视化方式。

在地图场景下，热力图通常把一批带坐标的数据点投影到地图上，然后根据点的数量、权重、聚集程度，渲染成从冷到热的颜色过渡区域，例如：

- 蓝色、绿色表示较低密度
- 黄色、橙色表示中等密度
- 红色表示高密度热点

它适合回答这类问题：

- 哪些区域数据点更集中
- 哪些区域事件更频繁
- 某类资源、人流、车辆、订单在空间上的热点分布如何

## 2. 热力图的核心特点

热力图和普通散点图的区别在于，它不强调单个点的位置，而更强调整体分布趋势。

常见特点：

- 适合大规模点位展示，避免地图上出现大量点重叠
- 更容易识别热点区域和冷点区域
- 可以支持权重值，不同点对热度贡献不同
- 适合做趋势观察，不适合精确查看单个点明细

## 3. 常见应用场景

- 人流热区分析
- 车辆轨迹停留热点分析
- 订单分布分析
- 设备告警分布分析
- 门店、站点、网点覆盖热区分析
- 用户行为点击热区分析

在 GIS 或业务系统中，热力图常被用于“先看全局分布，再下钻看明细”。

## 4. 热力图的基本实现思路

地图热力图一般基于以下信息生成：

1. 坐标点：每条数据至少要有经纬度
2. 权重值：可选，例如人流量、订单量、告警次数
3. 渲染半径：控制每个点影响周边区域的范围
4. 颜色梯度：定义从低热度到高热度的颜色映射
5. 透明度与缩放：影响视觉效果和不同层级下的展示

简化理解：

- 一个点不是只影响自身像素
- 它会向周边扩散形成一片“热度影响范围”
- 多个点叠加后，颜色越热，表示该区域综合权重越高

## 5. 热力图的优点与局限

优点：

- 对空间分布的表达直观
- 能快速发现热点区域
- 对海量点位比散点图更友好

局限：

- 不适合查看单个点精确位置
- 参数对效果影响较大，例如半径、透明度、最大值
- 数据过少时，热力图意义不明显
- 容易给人“边界很清晰”的错觉，但本质上它通常是平滑后的视觉表达

## 6. 高德地图中的热力图

高德地图支持热力图能力，常见于其 JavaScript 地图可视化方案中。一般做法是：

- 先初始化地图
- 引入热力图相关插件或能力
- 传入一组带经纬度的数据
- 配置半径、透明度、颜色梯度、最大热度值等参数
- 调用接口渲染热力图图层

高德热力图通常具备这些能力：

- 支持基于经纬度点数据渲染
- 支持 `count` 或类似权重字段，表示点的热度贡献
- 支持设置热力半径 `radius`
- 支持设置透明度 `opacity`
- 支持设置颜色渐变 `gradient`
- 支持显示或隐藏图层

从使用习惯上看，高德热力图更偏前端渲染层能力，适合在浏览器端直接展示分析结果。

## 7. 高德热力图常见数据格式

常见输入数据通常类似这样：

```json
[
  { "lng": 116.397428, "lat": 39.90923, "count": 10 },
  { "lng": 116.405285, "lat": 39.904989, "count": 30 },
  { "lng": 116.389906, "lat": 39.914889, "count": 18 }
]
```

字段含义：

- `lng`：经度
- `lat`：纬度
- `count`：权重或热度值

如果没有权重字段，也可以把每个点视为相同权重。

## 8. 使用高德热力图时的注意点

### 8.1 坐标系问题

高德地图使用的是 GCJ-02 坐标系。如果你的原始数据来自 GPS，往往是 WGS84，需要确认是否需要做坐标转换，否则会出现点位偏移。

### 8.2 数据量与前端性能

热力图本质上是前端渲染。点位非常多时，需要关注：

- 浏览器性能
- 渲染卡顿
- 缩放和拖拽时的响应速度

必要时可以先在后端做聚合，或者按视野范围加载数据。

### 8.3 参数调优很重要

同一批数据，`radius`、`max`、`opacity`、`gradient` 不同，视觉结果会差很多。实际项目中通常需要结合业务反复调参。

### 8.4 热力图不等于聚合点

热力图强调“连续的热度分布”，聚合点强调“把点合并成数量标记”。两者用途不同：

- 热力图适合看趋势和热点
- 聚合点适合看数量和分层展开

## 9. 适合在业务系统中怎么用

如果是车联网、订单、巡检、设备监控这类系统，热力图通常可以这样落地：

- 统计某时间段内事件发生位置，生成事件热力图
- 统计车辆停留位置，生成停车热点图
- 统计告警分布，定位高频问题区域
- 统计用户活跃点，分析重点区域覆盖情况

一个比较实用的组合方式是：

- 缩小时显示热力图看全局
- 放大后切换散点或聚合点看明细

## 10. 总结

热力图本质上是一种空间密度可视化方式，用颜色强弱表达“哪里更热”。它特别适合地图上的点分布分析。

高德地图提供了较成熟的热力图展示能力，适合前端直接渲染业务点位热点。实际使用时，要特别注意：

- 坐标系是否正确
- 数据量是否适合前端渲染
- 参数是否经过调优
- 是否需要与聚合点、散点图组合使用
