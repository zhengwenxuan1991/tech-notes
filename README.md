## 如何同步

公开内容由白名单 `publish.txt` 从私有笔记库同步而来。在本仓根目录执行：

```bash
./scripts/sync-from-private.sh
```

脚本会拷贝白名单文件、应用脱敏、跑敏感扫描；**不会**自动 commit/push。详见 [SYNC.md](SYNC.md)。

仅扫描：

```bash
./scripts/scan-sensitive.sh
```
