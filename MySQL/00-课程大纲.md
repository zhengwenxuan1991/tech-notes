# MySQL 深水区 · 课程大纲

> 学员背景：10 年+ Java 后端，MySQL 内核原理从零起步（摸底 8 题待攻克）。版本基准：**MySQL 8.0 / InnoDB**。

## 6 周路线

```mermaid
flowchart LR
  W1[第1周 InnoDB 存储] --> W2[第2周 索引与代价] --> W3[第3周 事务与锁] --> W4[第4周 SQL 与执行计划] --> W5[第5周 复制与高可用] --> W6[第6周 架构演进]
```

| 周 | 主题 | 核心内容 |
|---|---|---|
| 1 | InnoDB 存储 | 页、行格式、Buffer Pool、redo log、undo log、binlog |
| 2 | 索引与代价 | B+Tree、回表、覆盖索引、ICP（索引条件下推）、优化器如何选索引 |
| 3 | 事务与锁 | MVCC、隔离级别、行锁/间隙锁/临键锁、死锁分析 |
| 4 | SQL 与执行计划 | EXPLAIN、慢查询日志、join 改写 |
| 5 | 复制与高可用 | binlog 格式、主从延迟、并行复制、半同步、主从切换 |
| 6 | 架构演进 | 分区表、分库分表、分片键选择 |
