# 证书相关名词与概念

## 一、PKCS 系列标准

PKCS（Public-Key Cryptography Standards，公钥密码学标准）是由 RSA 实验室制定的一系列标准。

| 标准 | 名称 | 用途 |
| --- | --- | --- |
| **PKCS #1** | RSA Cryptography Standard | 定义 RSA 加密算法的数学基础、数据格式（如 RSA 公钥/私钥的 ASN.1 编码）、加密和签名方案（如 PKCS#1 v1.5 填充、OAEP、PSS） |
| **PKCS #7** | Cryptographic Message Syntax (CMS) | 定义加密消息的语法格式，常用于数字签名、S/MIME 邮件加密、代码签名。即 `.p7b` 或 `.p7c` 文件格式 |
| **PKCS #8** | Private-Key Information Syntax Standard | 定义私钥的存储格式，支持加密保护。`.key` 文件常用此格式 |
| **PKCS #10** | Certification Request Syntax Standard | 定义证书签名请求（CSR）的格式，用于向 CA 申请证书 |
| **PKCS #12** | Personal Information Exchange Syntax Standard | 定义私钥+证书的打包格式，支持密码保护。即 `.p12` 或 `.pfx` 文件 |
| **PKCS #11** | Cryptographic Token Interface | 定义与硬件加密设备（如 HSM、USB Key）交互的 API 接口 |

## 二、核心概念

### 1. X.509 证书
- **定义**：国际标准（ITU-T）的数字证书格式，定义了证书的结构和字段
- **核心字段**：
  - Version（版本）
  - Serial Number（序列号）
  - Issuer（颁发者）
  - Subject（使用者/主体）
  - Validity（有效期：Not Before / Not After）
  - Public Key Info（公钥信息）
  - Signature Algorithm（签名算法）
  - Signature Value（签名值）
- **常见扩展**：Subject Alternative Name (SAN)、Key Usage、Extended Key Usage

### 2. ASN.1（Abstract Syntax Notation One）
- **定义**：一种描述数据结构和编码规则的标准语言
- **作用**：证书、密钥等密码学对象都用 ASN.1 定义结构
- **编码规则**：
  - **DER**（Distinguished Encoding Rules）：二进制编码，唯一确定
  - **BER**（Basic Encoding Rules）：DER 的超集，允许多种编码方式
  - **PEM**（Privacy-Enhanced Mail）：DER 的 Base64 编码，加 `-----BEGIN...-----` 头尾

### 3. 常见文件格式

| 扩展名 | 格式 | 内容 |
| --- | --- | --- |
| `.cer`, `.crt` | DER/PEM | 仅证书（公钥） |
| `.key` | DER/PEM | 私钥（PKCS#8 或传统格式） |
| `.csr` | PEM | 证书签名请求（PKCS#10） |
| `.p7b`, `.p7c` | PEM/DER | 证书链（PKCS#7），不含私钥 |
| `.pfx`, `.p12` | 二进制 | 私钥+证书打包（PKCS#12） |

### 4. CSR（Certificate Signing Request）
- **定义**：证书签名请求，申请者向 CA 提交的申请文件
- **内容**：申请者的公钥 + 主体信息（CN/O/OU/C 等）+ 签名
- **流程**：生成密钥对 → 创建 CSR → 提交给 CA → CA 验证 → 签发证书

### 5. CA（Certificate Authority）
- **定义**：证书颁发机构，受信任的第三方
- **类型**：
  - **根 CA**（Root CA）：自签名证书，信任锚点
  - **中间 CA**（Intermediate CA）：根 CA 签发，用于签发终端证书
- **证书链**：终端证书 → 中间 CA 证书 → 根 CA 证书

## 三、加密算法相关

### 1. 非对称算法
| 算法 | 密钥长度 | 特点 |
| --- | --- | --- |
| RSA | 2048/4096 bit | 最广泛使用，基于大数分解难题 |
| ECC | 256/384 bit | 更短密钥同等安全性，移动端友好 |
| SM2 | 256 bit | 国密标准，基于椭圆曲线 |

### 2. 填充方案（PKCS#1 定义）
- **PKCS#1 v1.5**：传统填充，易受选择密文攻击
- **OAEP**（Optimal Asymmetric Encryption Padding）：加密用，安全性更高
- **PSS**（Probabilistic Signature Scheme）：签名用，可证明安全

### 3. 签名算法
| 算法 | 说明 |
| --- | --- |
| SHA256withRSA | SHA-256 哈希 + RSA 签名 |
| SHA384withECDSA | SHA-384 哈希 + ECDSA 签名 |
| SM3withSM2 | 国密签名算法 |

## 四、证书验证流程

```
1. 验证签名（用颁发者公钥验证）
2. 检查有效期（Not Before ≤ 当前时间 ≤ Not After）
3. 检查证书吊销状态（CRL 或 OCSP）
4. 验证证书链完整性
5. 检查 Key Usage / Extended Key Usage
6. 检查域名匹配（CN 或 SAN）
```

## 五、常用命令（OpenSSL）

```bash
# 查看证书内容
openssl x509 -in cert.pem -text -noout

# 查看 CSR 内容
openssl req -in request.csr -text -noout

# 查看私钥
openssl rsa -in private.key -text -noout

# 生成密钥对
openssl genrsa -out private.key 2048

# 生成 CSR
openssl req -new -key private.key -out request.csr

# 证书格式转换
openssl x509 -in cert.der -inform DER -out cert.pem -outform PEM

# PKCS#12 转换
openssl pkcs12 -in archive.p12 -out cert.pem -nodes
```

## 六、相关标准组织

| 组织 | 说明 |
| --- | --- |
| IETF | 制定 PKIX（X.509 互联网应用）、TLS 等标准 |
| ITU-T | 制定 X.509、ASN.1 等国际标准 |
| RSA Labs | 制定 PKCS 系列标准 |
| NIST | 美国国家标准，定义加密算法规范 |
| GM/T | 中国国密标准（SM2/SM3/SM4 等） |
