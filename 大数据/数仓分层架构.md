# 数仓分层架构

> [!abstract] 概述
> 数据仓库的建设通常遵循标准的分层架构，目的是为了**降低数据开发成本、解耦处理流程、提升数据复用性**并**保障数据口径的一致性**。业界主流的数据仓库一般划分为以下几个核心层级：
>
> `ODS → DWD → DIM → DWM/DWI（可选） → DWS/DM → ADS/APP`

---

## 1. ODS 层 — 数据接入层

> **Operational Data Store**（操作数据存储层）

- **定义**：原始数据的存档区和缓冲区，是最接近数据源的最底层。
- **作用**：
	- 直接对接各种业务系统（如业务数据库、日志系统等）。
	- 负责**全量或增量同步原始数据，不修改原有的数据结构和内容**（保留空值、脏数据等原貌）。
	- 主要使命是将基础数据引入数仓，用于历史数据备份、问题溯源，以及在后续 ETL 处理出错时能够快速回溯和重跑任务。

## 2. DWD 层 — 数据明细层

> **Data Warehouse Detail**（数据仓库明细层 / 基础数据层）

- **定义**：基于 ODS 层数据加工而成的原子粒度（最细粒度，如单笔订单、单次点击）明细事实数据。
- **作用**：
	- 对 ODS 层的原始数据进行**深度清洗**（过滤脏数据、去空值、去重）。
	- **规范化处理**（统一时间格式、字段命名、状态定义等）。
	- **打宽表处理**（结合维度属性进行适当冗余）。
	- 是整个数据仓库的**核心基石层**，为上层的所有统计分析提供干净、一致的底层明细数据支撑。

## 3. DIM 层 — 公共维表层

> **Dimension**（维度字典层）

- **定义**：基于维度建模理念构建的，用于存储业务实体的描述性属性（如用户资料、商品基本属性、日期、地理区域等）的数据层。
- **作用**：
	- 建立整个企业**一致性的业务维度字典**，独立于事实表并被多个业务复用。
	- 为 DWD、DWS 和 ADS 层提供丰富的维度字段说明。
	- 避免数据计算口径和算法不统一的风险。

## 4. DWM / DWI 层 — 数据中间层（可选）

> **Data Warehouse Middle / Integration**（数据中间层 / 数据整合层）

- **定义**：在 DWD 层数据基础上构建的轻度聚合或跨域整合的中间数据表。
- **作用**：
	- 主要为了**提升公共指标的复用性，减少重复加工**。
	- **DWI 层**：将不同业务域（订单、物流等）的数据关联整合，统一异构数据的口径。
	- **DWM 层**：对通用的核心维度进行初步聚合，算出中间统计指标，以便下游进一步拼接宽表。

## 5. DWS / DM 层 — 公共汇总层

> **Data Warehouse Summary / Data Mart**（公共汇总层 / 数据集市层）

- **定义**：基于 DWD 或 DWM 层数据，以特定的业务分析主题、对象或产品需求为驱动，构建的公共粒度汇总指标事实宽表。
- **作用**：
	- 对数据按天、周、月或特定维度（如城市、品类、用户）进行**粗粒度的预计算和汇总聚合**。
	- 沉淀高复用的核心指标（如日活跃用户、总交易额等）。
	- 大大减少上层的重复计算量，提升查询性能。
	- 通常能覆盖 **80%** 的通用分析场景。

## 6. ADS / APP 层 — 数据应用层

> **Application Data Service**（数据应用层）

- **定义**：位于数仓架构的最顶层，存放面向特定业务场景、数据产品或部门需求的高度个性化和定制化的统计指标结果数据。
- **作用**：
	- 直接支撑最终的业务应用，如 **BI 报表展示、数据大屏可视化、风控模型、推荐系统或 API 接口**。
	- 通常会根据 DWS/DWD 层加工出结果集后，导出到 MySQL、Redis、ElasticSearch 等在线存储引擎中，供前端应用直接高效查询使用。

## 分层对比速查

| 层级 | 英文名 | 中文名 | 核心职责 | 数据粒度 |
| :---: | :--- | :--- | :--- | :--- |
| ODS | Operational Data Store | 数据接入层 | 原始数据同步，保持原貌 | 原始未处理 |
| DWD | Data Warehouse Detail | 数据明细层 | 清洗、规范化、打宽表 | 最细粒度（原子） |
| DIM | Dimension | 公共维表层 | 统一维度字典 | 维度属性 |
| DWM | Data Warehouse Middle | 数据中间层 | 轻度聚合，提升复用 | 轻度聚合 |
| DWS | Data Warehouse Summary | 公共汇总层 | 预计算汇总核心指标 | 粗粒度汇总 |
| ADS | Application Data Service | 数据应用层 | 面向业务场景的定制输出 | 高度汇总 |
